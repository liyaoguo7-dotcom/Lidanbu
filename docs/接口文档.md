# 接口文档（T1.x）

> 阶段1：`core/` 纯函数接口（本地已测）。云函数 `api` 为薄封装，action 与下表一一对应，待云环境联调。

## 通用约定

- 所有接口先走 `authz.check`（T1.2），再走额度/会员检查（T1.5）；任一失败抛错。
- 金额单位：分（整数）。
- 审计：增删改、共享、授权变更自动记 `auditLogs`。

## 邀请奖励（core/invite-reward.js）

| 接口 | 说明 |
|---|---|
| inviteReward.getOrCreateInviteCode(db, userId) | 我的邀请码（懒生成、唯一、稳定） |
| inviteReward.bindInvite(db, inviteeId, {code, deviceId?}) | 绑定邀请关系；拒绝码：invite-disabled / invite-code-invalid / invite-self / invite-already-bound / invite-not-new-user（新用户判定：名下无礼薄/收礼/送礼记录） |
| inviteReward.checkEligibility(db, inviteeId) | 有效动作检查（确认口径）：(礼薄≥1 且 有收礼亲友) 或 有送礼亲友；「亲友」= 本人新建联系人（createdBy=本人、排除 seed 种子联系人、旧数据无 createdBy 不算）且被用于 ≥1 条对应记录；返回含 receiveFriend/giftFriend/ownNewContacts 明细 |
| inviteReward.evaluateInvite(db, inviteeId, {deviceId?}) | 评估并发放（幂等）：写 InviteRewardGrant + 审计(grant/inviteReward)；未达条件/上限/同设备重复只返回 reason 不发放 |
| inviteReward.getMyInviteSummary(db, userId) | 我的页/邀请页汇总：邀请码、成功数/上限/剩余、已得池与送礼、记录列表（被邀请人脱敏）、我自己的被邀绑定 |
| admin.updateInviteSettings(db, actorId, {enabled?, perInvite?, maxSuccessfulInvites?}) | 仅管理员；写 appConfig 文档 + 配置审计；改上限/奖励数对之后发放立即生效 |
| dataService.getInviteSummary / bindInviteCode / bindPendingInvite | 小程序侧入口：汇总（先静默评估）、手动输码绑定、启动时绑定分享带入的码 |

## 任务AF 增补（第一版发布口径 + 性能，2026-10-24）

| 接口 | 说明 |
|---|---|
| payment.purchase / purchasePointsPack（云端闸门） | api 分发在注入 Mock 适配器时一并注入 `opts.cloudGate={enabled,isAdmin}`（enabled 读 appConfig 文档 `payment.enabled`，缺省静态 `payment.enabled=false`；isAdmin 读文档 `adminIds`）。core 在建单前校验：关闸且非管理员抛 `payment-closed`（文案「会员购买暂未开放，敬请期待」），不建单不发货；放行时凡模拟渠道订单落 `mock:true` 标记（建单两处同口径）。本地演示不注入 cloudGate、不受闸 |
| features.getFlags(db, actorId) | 公开只读：生效功能开关 `{photoImport}`（文档 `features.photoImport` 优先、静态 `features.photoImport=false` 兜底）；页面据此决定拍照入口行为 |
| importer.startImportTask / writeImport（云端闸门） | api 分发给最后一个参数注入 `cloudGate:true`；core 在最前面校验开关：关 → 抛 `photo-import-closed`（文案「拍照导入敬请期待」），识别与写入双拒（防绕过页面）。本地调用不注入、不受闸 |
| admin.getConfig（增补字段） | 返回增补 `paymentEnabled`、`photoImportEnabled`（文档段优先、静态默认兜底），老板平台配置页「支付平台开关」区可见可改 |
| admin.updateLaunchSwitches(db, actorId, {paymentEnabled?, photoImportEnabled?}) | 仅管理员；布尔校验后整段写 `payment:{enabled}` / `features:{photoImport}` 并审计（action=config）；返回两开关生效值 |
| admin.isAdmin(db, actorId) | 「我的」页隐藏入口显隐的唯一依据（经 dataService.isAdmin 暴露给页面）：只认服务端文档 `adminIds`；非管理员连点版本号不计数、不提示、不跳转 |
| api 定时保活 | `cloudfunctions/api/config.json` 配 timer 触发器（每 5 分钟）；main 收到 `Type:'timer'` 事件空转返回 `{ok:true, warm:true}`，目的为减少冷启动 |
| api ensureServerUser 进程内缓存 | 同一函数容器内已确认建号的 openid 跳过 users 读；账号限制由 restriction 在写入口独立查，不受缓存影响 |

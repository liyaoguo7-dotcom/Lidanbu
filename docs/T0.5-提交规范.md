# T0.5 Git 提交规范

> 仓库：https://github.com/liyaoguo7-dotcom/Lidanbu（私有）｜ 主分支：`main`

---

## 一、提交频率

- 每完成一个任务（T0.1、T0.2…）提交一次，不得攒多个任务一次提交
- 阶段报告、验收文档单独提交

## 二、提交说明格式

```
T<x.y> <任务名>：<改了什么>
```

- 第一行：任务编号 + 任务名 + 冒号 + 一句话改动摘要
- 正文（换行后）：分条列出关键改动文件与自检结果
- 示例：
  ```
  T0.2 通用组件：7个组件 + demo示例页

  - add-btn：红色+按钮（底部中间固定）
  - tag-selector：10标签选择器（从配置读取）
  - 自检：JSx8/JSONx8 全过
  ```

## 三、铁律

1. **绝不提交密钥**：AppSecret、支付密钥、云开发密钥、`.env`、私钥文件一律不进仓库
2. `project.private.config.json` 不提交（已在 `.gitignore`）
3. 提交前跑一遍基础自检（JSON 合法、JS 语法）
4. 中文提交说明，写清"改了什么"，不写"更新""修改"这类空话
5. 不 force-push、不改写已推送历史

## 四、分支策略（当前）

- 阶段 0：直接在 `main` 提交（任务粒度小、单人执行）
- 阶段 1 起如并行开发，另议分支策略（届时由总指挥定）

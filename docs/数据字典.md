# 数据字典（T1.1）

> 基线：v3.1 §17.2 ｜ 金额一律整数"分" ｜ 不设 RecycleBin、不设 ReceiveProject

## users（用户）

| 字段 | 类型 | 说明 |
|---|---|---|
| _id | string | openid（云开发 `getWXContext` 获取） |
| inviteCode | string | 我的邀请码（8 位，懒生成、全局唯一；老用户可为空直到首次打开邀请页） |
| membership.status | string | free / member |
| membership.expireAt | number | 会员到期时间戳；free 为 null |
| membership.graceUntil | number | 缓冲期结束（派生，冗余存储可为空） |
| createdAt | number | |

## contacts（亲友录联系人）

| 字段 | 类型 | 说明 |
|---|---|---|
| _id | string | 稳定 ID，记录绑定此 ID |
| ownerId | string | 账本主人 openid |
| name | string | 姓名（显示字段，可改） |
| remark | string | 备注，可空 |
| createdBy | string | 创建者 openid（邀请奖励"本人新建亲友"判定用；旧数据可能缺失，缺失不算本人新建） |
| seed | boolean? | true = 演示种子联系人（系统预置）；普通新建无此字段。种子联系人不算"本人新建亲友" |
| createdAt | number | |

约束：只有姓名+备注；重名只提醒不合并。

## inviteBindings（邀请关系绑定记录）

每位被邀请人最多一条；账号注销清理时**不删除**（与发放记录一起防止"注销后重注册重复计数"）。只存 id/邀请码/时间，不存账本内容。

| 字段 | 类型 | 说明 |
|---|---|---|
| _id | string | |
| inviterId | string | 邀请人 |
| inviteeId | string | 被邀请人 |
| code | string | 绑定用的邀请码 |
| deviceId | string\|null | 设备指纹占位（可注入；真机采集待联调） |
| status | string | 'bound' 已绑定待完成条件 \| 'granted' 已发放 \| 'blocked' 设备重复被拦 |
| boundAt | number | 绑定时间 |
| grantedAt | number\|null | 发放时间 |

## inviteRewardGrants（邀请奖励发放记录）

**只存数量与时间，不存账本内容。** 每对（邀请人, 被邀请人）最多一条，是邀请奖励额度的唯一真源（额度按记录计数 × 生效配置计算）。

| 字段 | 类型 | 说明 |
|---|---|---|
| _id | string | |
| userId | string | 邀请人 |
| invitedUserId | string | 被邀请人 |
| poolGranted | number | 本次发放的收礼池额度数 |
| giftsGranted | number | 本次发放的送礼额度数 |
| deviceId | string\|null | 领取时设备指纹占位（防同设备重复领取） |
| grantedAt | number | 发放时间 |

## shareOverview（老板平台预留：家庭共享概况，派生视图非集合）

**只存数量，不读账本内容**（不读礼金、联系人、备注）。

| 字段 | 类型 | 说明 |
|---|---|---|
| ownerId | string | 账本主人 |
| memberCount | number | 成员总数 |
| activeMemberCount | number | 有效成员数 |
| authorizedEventCount | number | 已授权事件数 |
| updatedAt | number | |

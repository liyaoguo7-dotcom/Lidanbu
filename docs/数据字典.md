# 数据字典（T1.1）

> 基线：v3.1 §17.2 ｜ 金额一律整数"分" ｜ 不设 RecycleBin、不设 ReceiveProject

## users（用户）

| 字段 | 类型 | 说明 |
|---|---|---|
| _id | string | openid（云开发 `getWXContext` 获取） |
| membership.status | string | free / member |
| membership.expireAt | number | 会员到期时间戳；free 为 null |
| membership.graceUntil | number | 缓冲期结束（派生，冗余存储可为空） |
| createdAt | number | |

## contacts（亲友录联系人）

| 字段 | 类型 | 说明 |
|---|---|---|
| _id | string | 稳定 ID，记录绑定此 ID |
| ownerId | string | 账本主人 openid |
| name | string | 姓名（显示字段，可改） |
| remark | string | 备注，可空 |
| createdAt | number | |

约束：只有姓名+备注；重名只提醒不合并。

## receiveEvents（收礼礼薄）

| 字段 | 类型 | 说明 |
|---|---|---|
| _id | string | |
| ownerId | string | |
| name | string | 礼薄名称；同一账本内查重（第19章#16建议，待确认） |
| tagId | string | 10 标签之一 |
| date | string | YYYY-MM-DD |
| remark | string | |
| createdAt | number | |

## receiveRecords（收礼明细）

| 字段 | 类型 | 说明 |
|---|---|---|
| _id | string | |
| ownerId / eventId | string | |
| contactId | string | 联系人稳定 ID |
| amount | number | 整数分 |
| type | string | 红包/现金/转账/微信/支付宝 |
| remark / date | string | |
| createdBy | string | 创建者 openid（成员新增保留"谁加的"） |
| createdAt | number | |

## giftRecords（送礼记录）

| 字段 | 类型 | 说明 |
|---|---|---|
| _id / ownerId / contactId | string | 同上 |
| tagId | string | 10 标签之一 |
| amount | number | 整数分 |
| remark / date / createdBy / createdAt | | 同上 |

## shareMemberships（共享成员关系）

| 字段 | 类型 | 说明 |
|---|---|---|
| _id | string | |
| ownerId | string | 账本主人 |
| memberId | string | 成员 openid（pending 时为空） |
| status | string | pending / active / removed |
| createdAt | number | |

## shareGrants（授权单）

| 字段 | 类型 | 说明 |
|---|---|---|
| _id / membershipId | string | |
| switches | object | {view,add,edit,del,export}；view 恒 true；export 默认 false |
| scope | object | {events:[eventId], gifts:bool}；新事件默认不共享 |
| updatedAt | number | |

## auditLogs（审计）

| 字段 | 类型 | 说明 |
|---|---|---|
| _id / ownerId / actorId | string | |
| action | string | create/update/delete/share/grant/export |
| targetType / targetId | string | |
| detail | string | 摘要，**不含金额和姓名原文** |
| createdAt | number | |

## importJobs / exportJobs（阶段4/3用，T1.1只建模）

| 字段 | 类型 | 说明 |
|---|---|---|
| _id / ownerId | string | |
| kind/scope/status | string | 任务类型/范围/状态 |
| createdAt | number | |

## appConfig（应用配置）

| 字段 | 类型 | 说明 |
|---|---|---|
| _id | string | 固定 'singleton' |
| freeQuota | object | 免费额度（3/30/30/50） |
| membership.quota | object | 会员额度（占位，待定价） |
| membership.expiry | object | 缓冲期30天、三次提醒规则 |
| memberOnlyFeatures | string[] | 会员专属功能清单：['familyShareInvite','photoImport','landscapeMode'] |
| inviteReward | object | **预留**：{enabled:false, rules:{perInvite:{receivePool:10,giftRecords:5}, maxInvites:10}}；上限含义待确认 |
| updatedAt | number | |

## inviteRewardGrants（老板平台预留：邀请奖励发放记录）

**只存数量与时间，不存账本内容。** 邀请功能上线后启用。

| 字段 | 类型 | 说明 |
|---|---|---|
| _id | string | |
| userId | string | 邀请人 |
| invitedUserId | string | 被邀请人 |
| poolGranted | number | 本次发放的收礼池额度数 |
| giftsGranted | number | 本次发放的送礼额度数 |
| grantedAt | number | 发放时间 |

## shareOverview（老板平台预留：家庭共享概况，派生视图非集合）

**只存数量，不读账本内容**（不读礼金、联系人、备注）。

| 字段 | 类型 | 说明 |
|---|---|---|
| ownerId | string | 账本主人 |
| memberCount | number | 成员总数 |
| activeMemberCount | number | 有效成员数 |
| authorizedEventCount | number | 已授权事件数 |
| updatedAt | number | |

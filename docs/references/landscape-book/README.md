## 参考 1：纸质礼金簿（现代款）— ref1-纸质礼金簿.jpg
- **来源**：Pinkoi 设计商品页 https://en.pinkoi.com/product/fikKLcSM （图片为该商品展示图）
- **字体风格**：内页为现代印刷黑体/宋体，分栏标题小字；封面手写英文花体
- **好在哪里**：内页"编号 / 姓名 / 礼金 / 备注"分栏清晰，一人一行，留白多，找人快
- **适合我们的地方**："一人一列"的分栏思路可以直接借鉴——横置模式下一人一列，每列内姓名在上、大写金额在下
- **说明**：传统手写红字礼簿内页实拍在网上极少，此图为现代纸质礼簿。传统版式规则见下文引用。

## 参考 2：电子礼金簿 App 界面 — ref2-电子礼金簿App.png
- **来源**：App 下载站宣传图，页面 https://www.xjqakj.com/sjapp/272886.html （"礼金礼品都能记"）
- **字体风格**：系统黑体（苹方类），数字为等宽数字体，干净的数字化风格
- **好在哪里**：拼音分组 + "收 X 笔 / 送 X 笔"一眼可见；每人一行显示收/送金额与笔数
- **适合我们的地方**：联系人维度的汇总思路值得借鉴；但它没有红字、大写、横置——这正是我们会员"横置红字礼单本"的差异化卖点

## 参考 3：传统中式竖排版式美学 — ref3-传统竖排版式.jpg
- **来源**：图片搜索结果（Pinterest 站内图，无来源页，媒体地址 i.pinimg.com/originals/ca/e5/cc/cae5ccb578f6ed0e6ef6c278c583fad9.jpg）
- **字体风格**：书法体（英文花体签名）+ 宋体竖排正文，红金配色
- **好在哪里**：竖排从右到左的仪式感、红金配色的喜庆感、书法字体的文化味
- **适合我们的地方**：如果用户想要"仪式感拉满"的方向，可以借鉴竖排文字 + 红字 + 书法字体的美学；注意这是一张喜帖，不是礼簿，仅作美学参考

## 传统礼簿版式规则（文字引用，非图片）
以下规则来自《如何撰寫完美的禮簿》https://lunar-traditions.com/perfect-gift-book-guide/ ，与 v3.1 需求一致，可作为版式依据：
- 传统直式礼簿**由右至左**书写；现代横式由左至右
- 金额用**国字大写**，如"壹仟元整""壹萬元整"，不用阿拉伯数字
- 婚礼用双数金额、喜庆贺词；丧礼用单数金额、"节哀顺变"等慰问词（白事忌红）
- 署名：个人写全名；夫妻可写"伉俪"/"全家"；公司写"单位+职称+姓名"

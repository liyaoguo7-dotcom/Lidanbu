## 三、核心设计说明

1. **额度公式集中化**：`quota.getEffectiveQuota(user)` = 免费额度 + 会员额度 + 邀请奖励额度；**邀请奖励 `getInviteRewardQuota` 固定返回 0**，`AppConfig.inviteReward` 预留 `{enabled:false, rules:null}`。邀请功能本阶段未做，规则等用户确定。
2. **授权实时查询**：无缓存，撤销/改权限立即生效（测试 4、25 已覆盖）。
3. **成员额度归属**：成员新增计账本主人额度（按第19章#4建议，待确认）。
4. **金额整数分**：全链路校验（测试 19）。

# OCR 选型报告（阶段4 拍照导入 · 供用户拍板）

> 结论前置：本报告只摆事实，不做推荐。用户拍板选定一家后才接入，本次不写任何接入代码。
> 凡标注"需核实"的，均未在公开渠道找到官方原文，需用户在对应后台/协议中核实，不要假设。

拍照导入的场景：用户拍纸质礼单照片 → 识别出姓名、金额等文字 → 生成可编辑文本对照原图 → 确认后写入。
按次计费（一张照片≈一次调用）；打印体为主、 handwriting 为辅。

---

## 候选1：微信小程序 OCR 接口（api.weixin.qq.com / 云调用）

- **接口**：`ocr.printedText`（通用印刷体）、身份证、银行卡、驾驶证、行驶证、车牌等；
  支持两种调用方式：云调用（`cloud.openapi.ocr`，wx-server-sdk）和 HTTPS。
- **价格**：官方未公开收费标准。第三方教程称"内测期间 500次/天"（菜鸟教程，非官方）；另有第三方文章称公众号 OCR"每天免费100次"（非官方）。
  → **需核实**：当前免费额度、超额后是否收费，请在微信公众平台后台核实。
- **识别效果**：`printedText` 针对印刷体；手写体支持情况**需核实**。
- **许可证与商用条款**：微信官方接口，随小程序主体资质使用；具体商用条款见微信公众平台相关协议，**需核实**。
- **数据留存与隐私风险**：图片需上传至微信服务器进行识别；数据留存政策未见公开说明，**需核实**官方协议。
  礼单照片含他人姓名与金额，属敏感信息，无论选哪家，接入前必须在《隐私政策》中披露该第三方处理，并经法务/用户审核。
- **失败是否计费**：未见公开条款，**需核实**（免费额度内调用无费用概念）。
- **接入成本**：三家中最低——云调用无需自建服务器、无需管理密钥，与现有云开发同体系。

## 候选2：腾讯云文字识别 OCR

- **价格**（已核实，来源：腾讯云开发者社区文章，2026-10-18 抓取）：
  每月 1000 次免费（以资源包形式发放、优先扣除）；后付费阶梯——月调用 ≤1万次 0.15元/次，
  ≤10万次 0.10元/次，≤100万次 0.06元/次；**通用印刷体与通用手写体同价**。
- **识别效果**：通用印刷体（第三方教程引用口径）标准版 96% / 高精度版 99% / 精简版 91%；
  支持中英日韩等多语言、旋转识别；官方案例称顺丰手写体字段准确率 98%。
  手写礼单建议拿真实照片实测后再定。
- **许可证与商用条款**：腾讯云标准云服务，按腾讯云服务协议商用；
  密钥（SecretId/SecretKey）必须放在云函数服务端，**绝不进前端代码和仓库**。
- **数据留存与隐私风险**：未见公开的数据留存承诺，**需核实**腾讯云服务协议/隐私条款；
  《隐私政策》第三方披露要求同上。
- **失败是否计费**：未见公开条款，**需核实**（不假设按成功计费）。
- **接入成本**：需单独的腾讯云账号与计费，云函数中调 SDK 或 HTTPS。

## 候选3：阿里云文字识别 OCR

- **价格**（已核实，来源：阿里云官方帮助文档《产品计费方式与定价规则详解-文字识别》）：
  每个 API 每月 200 次免费；后付费阶梯（以身份证识别计费示例：≤1万次 0.0825元/次，
  ≤10万次 0.0495元/次，≤50万次 0.0415元/次；通用文字识别具体单价以控制台为准）；
  预付费资源包更便宜（1 年有效期）。
  注意：**开通 OCR 会自动开通后付费且不可关闭**，需保证阿里云账户余额充足，否则欠费停服。
- **识别效果**：通用文字识别 / 高精版 / 手写体等 API 齐全；具体准确率数字本次未核实到官方口径，
  建议实测。
- **许可证与商用条款**：阿里云标准云服务；**每类识别服务需单独开通**；
  AccessKey 必须放在云函数服务端。
- **数据留存与隐私风险**：未见公开承诺，**需核实**服务协议；《隐私政策》第三方披露要求同上。
- **失败是否计费**：官方原文"按**实际成功调用量**×后付费单价扣款"，"未发生成功调用……均不会出现后付费扣款"
  → **失败不计费**（三家中唯一有官方原文的）。
- **接入成本**：与腾讯云类似，需单独账号、密钥管理、按 API 单独开通。

## 用户拍板前需确认的事（按顺序）

1. 在微信公众平台后台核实小程序 OCR 当前免费额度与收费政策。
2. 在腾讯云/阿里云官方文档与服务协议中核实：失败计费条款、数据留存与隐私条款。
3. 拿真实纸质礼单照片（打印体、手写各约 10 张）对候选实测识别效果，再做决定。
4. 产品决策（用户定）：OCR 调用是否计入会员权益、识别失败是否扣用户额度、额度与失败计费拦截走委婉文案（已定）。
5. 《隐私政策》中补充所选第三方的披露文案，经法务/用户审核后才可上线。

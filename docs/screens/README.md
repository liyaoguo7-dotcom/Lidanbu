# docs/screens/

本目录存放已建成的真实页面的静态截图（22 张，文件名即页面名）。

- 静态复刻渲染，非真机截图，仅用于版式存档。
- 复刻方法：按各页面 wxml/wxss/js 做 HTML 静态复刻（wx:if 取真分支、wx:for 展开 2–4 条示例数据），375px 宽 CDP 截图。
- 示例数据为占位（中文名、两位小数金额；成员/管理员页用脱敏示例），不代表真实数据。

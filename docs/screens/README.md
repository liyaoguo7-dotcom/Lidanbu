# docs/screens/

本目录存放已建成的真实页面的静态截图（24 张，文件名即页面名）。

- 静态复刻渲染，非真机截图，仅用于版式存档。
- 复刻方法：按各页面 wxml/wxss/js 做 HTML 静态复刻（wx:if 取真分支、wx:for 展开 2–4 条示例数据），375px 宽 CDP 截图。
- 示例数据为占位（中文名、两位小数金额；成员/管理员页用脱敏示例），不代表真实数据。

## admin/ 老板平台（版式存档）

`admin/` 子目录 16 张：老板平台全部 15 项功能各有截图（配置页 3 个分区各 1 张，另加入口页），明细与每项状态见 `admin/README.md`。任务M 后 15 项已全部接真接口，截图已按真页面重出（无骨架黄条）。

## landscape/ 横置礼单本（版式存档）

`landscape/` 子目录 10 张，均为 844×390 定版版式存档图（非真机截图）：

- 33–37：收礼横置五种样式（传统经典/淡蓝水波纹/梨花白/祥云金/竹青）；38：收礼白事；39：送礼传统经典（含奠仪列）；30：请横屏页。以上 8 张即设计定版原图（自 docs/wireframes/landscape/ 拷入，与定版图同源同版）。
- 42-半屏详情、43-样式面板：在定版图 33 基底上按真实页面结构合成的存档图（列高亮+底部半屏 / 字体三选+样式六选+字体署名），对应 miniprogram/pages/landscape/ 的真实页面交互。

## example/ 示例页（真实页面，截图占位）

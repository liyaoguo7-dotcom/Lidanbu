# 云环境切换步骤（本地演示 → 云开发）

> 当前状态：✅ **已于 2026-10-23（任务AD）切换完成**，`AppConfig.demo.localMode = false`（云模式，出厂默认）。
> 下面是当时的切换步骤存档。做之前先读完
> 《开通云开发与联调清单.md》（开环境、建集合、部署云函数的前置工作）。
>
> ⚠️ 落地方式与本文原设想有一处不同（以代码为准）：步骤 3 原计划把 data-service 的
> `_makeDb()` 换成 CloudDB 让小程序端直连数据库——**实际落地是小程序端不直连
> 数据库**（安全规则已全关）：data-service 改为按模式切换 core 绑定，云模式用
> `miniprogram/services/remote-core.js` 远程代理，全部读写经云函数 api 由服务端
> core 执行（见 `docs/云联调准备.md` 第二节权限模型）。页面层同样零改动。
> 本地调试要回演示模式：把 `localMode` 改回 `true` 重新编译即可（步骤 2 反向操作）。

---

## 步骤 1：填环境 ID（只改配置中心一处）

文件：`miniprogram/config/app-config.js`

1. 把文件靠开头的 `cloudEnvId: ''` 的空字符串换成云开发控制台里复制的**环境 ID**。
2. 其他文件不用改：`miniprogram/app.js` 启动时自动读这个值并执行
   `wx.cloud.init({ env: ..., traceUser: true })`；值为空时自动跳过
   （所以本地预览阶段一直不用管它）。

## 步骤 2：关掉本地模式

文件：`miniprogram/config/app-config.js`

```js
demo: { localMode: false },   // true=本地演示，false=走云开发
```

只改这一个值。页面代码不用动——页面只调 `services/data-service.js`，数据从哪来由它决定。

## 步骤 3：数据服务切云（已落地，方式见文首注记）

`miniprogram/services/data-service.js` 按 `localMode` 切换 core 绑定：
本地 = 本地 core + WxStorageDB；云 = `services/remote-core.js` 远程代理
（全部调用走云函数 api，服务端 core 执行）。**页面层零改动**已达成，
并由"全链路回环测试"（tests/test-cloud-loopback.js）在本地跑通整条链。

## 步骤 4：部署云函数 api

照《开通云开发与联调清单.md》第三部分：
1. 把 `core/` 与 `miniprogram/config/app-config.js` 复制进 `cloudfunctions/api/`。
2. 按《接口文档.md》把 action 分发写全。
3. 开发者工具右键 `cloudfunctions/api` →「上传并部署：云端安装依赖」。
4. 控制台确认 `api` 在云函数列表且状态正常。

## 步骤 5：5 项验证（照抄《开通云开发与联调清单.md》，逐项打勾）

| # | 验证项 | 怎么验（大白话） | 通过标准 |
|---|---|---|---|
| 1 | CloudDB 真实读写 | ①控制台数据库里手动加一条 `contacts` 记录，看小程序亲友录里能不能显示；②小程序里新增一条收礼记录，去控制台看有没有落库 | 两边互相看得见 |
| 2 | 云函数 api 端到端 | ①控制台→云函数→`api`→云端测试，发 `{action:'contact.create', params:{...}}` 看返回；②小程序里点"新增亲友"走真实调用 | 测试和真机都返回成功 |
| 3 | `cloud.getWXContext()` 取 openid | 云函数里加一行测试代码返回 `cloud.getWXContext().OPENID`，**真机预览**下调用，看返回的 openid 是否每次一致 | 能稳定拿到 openid |
| 4 | 真实云数据库并发/权限 | ①两台手机同时往同一礼薄加记录，看两条都写进去了没丢；②用没被授权的微信号调接口，看是不是被拒绝（`core/authz.js` 的逻辑） | 不丢数据、越权被拒 |
| 5 | `wx.cloud.callFunction` 真实调用链 | 从小程序按钮点下去 → 云函数 → 数据库 → 返回显示，全链路走一遍，看模拟器调试器 Network 面板 | 全链路无报错、数据正确 |

## 回退

哪一步卡住：把 `demo.localMode` 改回 `true`，小程序立刻回到本地演示模式，不影响已写好的页面。

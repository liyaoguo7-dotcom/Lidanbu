# 微信后台《用户隐私保护指引》填写稿

> ⚠️ **待法务审**：本稿与 `docs/legal/隐私政策.md` 措辞保持一致，法务定稿后如有改动，两处同步修改。
> 用途：用户（运营者）在微信公众平台后台填写《用户隐私保护指引》时逐项照抄。
> 填写位置：微信公众平台 → 小程序后台 →「设置」→「用户隐私保护指引」（以平台当前界面为准）。
> 原则：**只勾产品实际用到的，实际没用的坚决不勾**——勾了没用反而增加审核与合规风险。带 ★ 的是当前版本实际涉及的项。

---

## 一、逐项填写表

### ★ 1. 账号标识（openid）

| 栏位 | 填写内容 |
|---|---|
| 数据项 | 微信登录标识（openid） |
| 产品里是什么 | 你登录时微信给的一串匿名编号，用来区分不同用户的账本 |
| 收集目的（照抄） | 用于识别用户身份、分隔保存每个人的账本数据 |
| 收集方式 | 登录时由微信平台自动提供 |
| 后台建议 | 若后台有"微信登录/OpenID"类选项则勾选并填上行目的；没有单独选项时，在"其他信息"里按上面三行填写 |

### ★ 2. 昵称、头像

| 栏位 | 填写内容 |
|---|---|
| 数据项 | 微信昵称、头像 |
| 产品里是什么 | "我的"页顶部显示的昵称与头像 |
| 收集目的（照抄） | 仅用于在"我的"页面展示你自己的账号信息 |
| 收集方式 | 经你授权后由微信提供 |
| 后台建议 | 勾选"昵称、头像"，目的填上行。不授权不影响记账功能使用 |

### ★ 3. 用户输入的记账内容（核心数据）

| 栏位 | 填写内容 |
|---|---|
| 数据项 | 你主动填写/选择的内容：亲友姓名与备注、礼薄名称与日期、收礼与送礼的金额/类型/日期/备注 |
| 产品里是什么 | 亲友录、收礼礼薄、收礼记录、送礼记录的全部字段；亲友录只有姓名、备注两项，不收集手机号 |
| 收集目的（照抄） | 用于保存并展示你的人情往来账本、计算笔数与金额汇总、生成往来记录 |
| 收集方式 | 由你在页面中主动填写、选择后提交保存 |
| 后台建议 | 后台无完全对应类目时，选"用户输入/自定义内容"类项（名称以平台为准），目的照抄上行；不要勾"通讯录""手机号码"——产品不收集这两项 |

### ★ 4. 家庭共享关系与授权设置

| 栏位 | 填写内容 |
|---|---|
| 数据项 | 你邀请的家人、你为其勾选的权限开关、邀请接受时间；家人新增记录的记录人标记 |
| 产品里是什么 | 家庭共享的成员关系与五项权限设置（仅查看/可新增/可修改/可删除/可导出） |
| 收集目的（照抄） | 用于按你的授权让家人查看或共同记录你指定的账本内容 |
| 收集方式 | 由你主动发起邀请、勾选权限时产生 |
| 后台建议 | 并入第 3 项"用户主动操作产生的内容"填写，或在"其他信息"中单列，目的照抄上行 |

### ★ 5. 订单与会员信息

| 栏位 | 填写内容 |
|---|---|
| 数据项 | 会员订单状态、会员档位、开通与到期时间 |
| 产品里是什么 | 你购买会员后，微信虚拟支付回传给我们的订单结果（不含银行卡、支付密码） |
| 收集目的（照抄） | 用于开通会员权益、计算会员到期时间与额度 |
| 收集方式 | 支付完成后由微信支付平台回传 |
| 后台建议 | 勾选"订单信息"类项（如有），目的照抄上行 |

### ★ 6. 邀请奖励信息

| 栏位 | 填写内容 |
|---|---|
| 数据项 | 邀请码、邀请关系（邀请人与被邀请人的账号标识、绑定时间）、奖励发放记录（发放额度数量与时间） |
| 产品里是什么 | "邀请得名额"功能：你打开邀请页时生成的邀请码；好友用你的码完成绑定与首次记账后，给你发放记录额度 |
| 收集目的（照抄） | 用于判断邀请是否有效、向邀请人发放记录额度奖励、防止同一设备或同一账号重复领取 |
| 收集方式 | 你打开邀请页、好友输入或通过链接带入邀请码绑定时产生 |
| 后台建议 | 在"其他信息"中单列填写，目的照抄上行 |

### ★ 7. 设备信息

| 栏位 | 填写内容 |
|---|---|
| 数据项 | 设备标识（本机生成的随机标识）、设备型号与系统版本的大致信息 |
| 产品里是什么 | 随机标识只用于邀请奖励防重复领取；机型/系统信息用于横屏页面适配与故障定位。窗口尺寸与安全区只在本机计算、不上传 |
| 收集目的（照抄） | 用于防止邀请奖励被重复领取、适配不同手机的横屏显示、定位并修复程序错误 |
| 收集方式 | 使用相关功能时由设备提供/本地生成 |
| 后台建议 | 勾选"设备信息"，目的照抄上行 |

### 8. 照片（拍照导入，条件项）

| 栏位 | 填写内容 |
|---|---|
| 数据项 | 你主动拍摄或从相册选择的纸质礼单照片 |
| 产品里是什么 | "拍照导入"（会员功能）：照片用于识别礼单上的姓名与金额 |
| 收集目的（照抄） | 用于识别你提供的礼单照片中的文字，帮你快速录入记录 |
| 收集方式 | 由你在拍照导入功能中主动拍摄或选择后上传 |
| 后台建议 | **当前版本 OCR 服务商未定、照片不会发给任何第三方**：若提审版本包含拍照导入入口，按上行勾选"相册/相机（照片）"；若提审时该功能未开放，可暂不勾选，开放前再补填并同步更新隐私政策 |

### ★ 9. 导出的文件

| 栏位 | 填写内容 |
|---|---|
| 数据项 | 你主动生成的账本导出文件（Excel） |
| 产品里是什么 | "导出备份"：把你自己的账本数据生成 xlsx 文件发送给你本人 |
| 收集目的（照抄） | 用于按你的要求生成账本备份文件 |
| 收集方式 | 由你主动点击导出时生成 |
| 后台建议 | 一般无需在指引中单列；如后台有"文件"类项且要求声明，按上行填写 |

## 二、明确不要勾选的项（产品实际不用）

| 项 | 原因 |
|---|---|
| 手机号码 | 产品不收集亲友手机号，登录也不要求手机号 |
| 通讯录 | 从不读取 |
| 地理位置 | 从不获取 |
| 麦克风/录音 | 无语音功能 |
| 日历 | 不读写系统日历 |
| 蓝牙、摄像头（扫码外） | 无相关功能；拍照导入用的是相机/相册选图，见第一部分第 8 项的条件说明 |

## 三、指引末尾的固定栏位（照抄）

- **信息存储**：你的信息存储于微信云开发云数据库（境内），按账号隔离保存；保存期限与《隐私政策》第五条一致。
- **联系我们**：如对个人信息处理有疑问，通过小程序"我的"页客服入口联系我们，我们将在 15 天内回复。（运营者名称/邮箱待填写，与隐私政策第十三节同步补齐。）
- **未成年人**：未成年人请在家长陪同下使用，家长可联系我们删除相关信息。

# 云环境初始化（一次性，照着做）

> 新云环境部署的第一步。做完这份，再按 `docs/云联调准备.md` 往下走。

## 步骤

1. **部署 init 云函数**：微信开发者工具里右键 `cloudfunctions/init` →「上传并部署：云端安装依赖」，等提示成功。
2. **调用一次**：云开发控制台 →「云函数」→ 找到 `init` →「云端测试」，入参填 `{}`，运行。
   - 返回里 `createdCollections` 是新建的集合（13 个全在最好）；
   - `config: "created"` 表示默认配置写好了；
   - 重复调用是安全的：已有的集合和配置会被跳过，不会覆盖老板平台后来改过的值（除非你传 `{"forceConfig": true}` 强制重写，慎用）。
3. **把创始人设为管理员**（最重要的一步）：
   - 先拿到创始人自己的 openid：办法任选其一——① 在小程序里用创始人微信登录一次，去云控制台数据库 `users` 集合里看自己的那条 `_id`；② 用云函数云端测试打印 `cloud.getWXContext().OPENID`（需真机/模拟器登录态下从小程序端调用）。
   - 回到数据库 → `appConfig` 集合 → 打开 `_id` 为 `singleton` 的文档 → 把 `adminIds` 改成 `["刚才的openid"]`，保存。
   - 名单为空时**谁都不是管理员**（老板平台进不去，这是故意的安全设计，不是 bug）。
4. **收尾**：确认上面都对了，把 `init` 云函数从环境里**删除**（控制台云函数列表里删），避免日后误触。

## 默认配置里有什么

- 免费额度：礼薄 3 个 / 每礼薄 30 条 / 送礼 30 条 / 亲友 50 人（与产品定版一致）。
- 会员额度：占位数字（定价时再定，不要当真）。
- 会员到期：缓冲期 30 天、提醒三次（已定口径）。
- 邀请奖励：开启；每次成功邀请收礼池 +10、送礼 +5；每人最多计入 10 次（现行口径，老板平台可改）。
- 会员专属功能清单：家庭共享邀请、拍照导入、横置礼单本。

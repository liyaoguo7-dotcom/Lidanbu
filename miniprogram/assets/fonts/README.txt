横置礼单本字体说明

本目录三款字体均为「常用字预生成包」（常用字子集，字符集约 721 字：
百家姓 + 高频姓名用字 + 大写金额字），用户在样式面板选中哪款，页面才通过
wx.loadFontFace 加载哪款，并缓存加载标记。

- lxgw-wenkai.woff2   霞鹜文楷 LXGW WenKai（github.com/lxgw/LxgwWenKai）
- mashanzheng.woff2   马善政毛笔体 Ma Shan Zheng（Google Fonts）
- longcang.woff2      龙藏体 Long Cang（Google Fonts；按与另两款相同的字符集子集化，
                      其中 3 个生僻字该字体本身没有字形，运行时走回退链显示，不出方框）

三款字体均以 SIL Open Font License 1.1 发布，许可证副本见同目录 OFL-1.1.txt。
页面署名（样式面板底部）：横置礼单本字体：霞鹜文楷、马善政毛笔体、龙藏体（SIL OFL 1.1）
